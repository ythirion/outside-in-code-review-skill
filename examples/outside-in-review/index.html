13 Summary

Top 3 risks

  1. critical EOL runtime and vulnerable Swagger UI. netcoreapp3.1 gets no security patches and Swashbuckle 5.6.3 carries GHSA-qrmm-w75w-3wpx. A production risk as soon as the API is exposed.
  2. critical Global mutable static state. DataAccessLayer._db is a public static field shared by every request, mutated without locking, and reset by every new ParkService(): the seed data written in Program.InitializePark() is wiped when DI creates its own instance.
  3. critical Wrong data, green tests, no CI. GetDinosaursInZone returns dinosaurs with no species and every one flagged carnivorous, yet the tests pass because they only count items. Nothing runs them automatically.

Top 3 questions to validate with the team

  1. Are Confluent.Kafka and Polly deliberate workshop "fossils", or leftovers of a planned feature?
  2. Is the static DataAccessLayer an intentional legacy smell for the workshop, or should the exercise end with proper dependency injection?
  3. Was the CI workflow removed on purpose as part of the exercise?
