Coupling / cohesion

Global Data

critical

Db2/DataAccessLayer.cs:7 · DataAccessLayer._db

The whole park lives in public static Database _db. Every request, every test and every service instance reads and writes the same object, with no lock and no way to substitute it.

public static class DataAccessLayer
{
    public static Database _db;
    public static void Init() => _db = new Database();

Refactoring: Encapsulate Variable, then Replace Static with Instance: introduce an IParkRepository owning the dictionaries, register it as a singleton, inject it into ParkService.

Mutable Data — constructor resets shared state

critical

Class1.cs:21-25 · ParkService() · Program.cs:24

Creating a ParkService silently replaces the global store and re-seeds it. Instantiation order decides what data exists, which is the root of the "seed data wiped" defect.

public ParkService()
{
    DataAccessLayer.Init();
    Init();
}

Refactoring: Separate Query from Modifier: make the constructor side-effect free and move seeding to a dedicated, explicit startup step.

Insider Trading

critical

Db2/Database.cs:8-11 · ReflectionHelper.cs:8

Database declares _dinosaurs private, then hands it out through reflection on itself. Callers depend on a private field name that the compiler cannot check.

public static Dictionary<string, DinosaurEntity> Dinosaurs(Database db)
{
    return (Dictionary<string, DinosaurEntity>)ReflectionHelper.GetPrivateField(db, "_dinosaurs");
}

Refactoring: Expose the intent instead of the data: AddDinosaur, FindDinosaur methods on Database (or on the new repository), then delete ReflectionHelper.

Mutable Data — service edits persistence entities

critical

Class1.cs:94, 101, 116 · MoveDinosaur, ToggleZone

ParkService reaches into _db.Zones and mutates ZoneEntity.DinosaurCodes and AccessStatus in place, bypassing DataAccessLayer's own save methods. Persistence rules can no longer be enforced in one place.

Refactoring: Move Function: give the zone the behaviour (zone.Toggle(), zone.Release(name), zone.Admit(name)) and persist through the repository.

Data structures / modeling

The DinosaurEntity → Dinosaur mapping, with its inverted booleans, is written twice; the reverse mapping a third time. A fix in one copy will be missed in the others.

Primitive Obsession

significant

Class1.cs:53, 126-137 · CanSpeciesCoexist

Zones and dinosaurs are identified by display names, species are compared to string literals, and health is the string "Sick" or null. "T-Rex" and "Tyrannosaurus Rex" are different species to the code.

Refactoring: Replace Primitive with Object: ZoneName, Species (with a diet), HealthStatus enum; drive compatibility from species data instead of literals.
